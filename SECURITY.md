# Security Policy

## Supported versions

Security fixes are applied to the latest release only.

## Reporting a vulnerability

**Please do not open a public GitHub issue for security vulnerabilities.**

Report vulnerabilities by emailing **security@rackspace.com** with the subject line
`[airflow-api-client] Security vulnerability`. Include:

- A description of the vulnerability and its potential impact
- Steps to reproduce or a proof-of-concept (if available)
- The version(s) affected
- Any suggested mitigations you are aware of

See [Rackspace's Security Policy](https://www.rackspace.com/en-gb/information/legal/rsdp) for more
information on how we handle security reports.
